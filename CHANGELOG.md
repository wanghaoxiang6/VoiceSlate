# Changelog

All notable changes to this fork will be documented in this file.

## v0.1.0 - 2026-05-08

### Added

- Volcengine STT support with fast and higher-accuracy modes
- Local correction history
- Usage summary and monthly API cost estimates
- Windows fallback hotkey support with `F8`
- Public-release attribution and handoff docs

### Changed

- Rebranded the public fork as `VoiceSlate`
- Switched the default workflow to local-first BYOK usage
- Improved Windows focus restoration and output behavior
- Updated GitHub templates and release metadata for this fork

### Notes

- `Right Alt` remains available but may vary across Windows setups
- `F8` is the stable fallback hotkey
