# Contributing to VoiceSlate

Thanks for improving this fork.

## Before Opening A Public PR

- Make sure `LICENSE` and `NOTICE` stay intact
- Avoid committing local runtime data or API keys
- Keep public-facing branding consistent with this fork

## Local Development

```bash
npm install
npm run test
npm run build
```

If you later publish this repo to GitHub, update this file with your issue, discussion, and pull request conventions.
