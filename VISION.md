# Vision

VoiceSlate aims to be a practical local-first voice input desktop app that stays flexible about providers and workflows.

## Product Direction

- fast desktop dictation
- provider choice for STT and LLM
- local correction and usage feedback
- strong Windows usability
- no forced hosted subscription for core use

## Fork Positioning

This codebase is based on OpenTypeless and keeps attribution intact, while focusing on a more self-hosted and BYOK-friendly experience.
