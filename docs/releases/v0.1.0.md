# VoiceSlate v0.1.0

First public release of the VoiceSlate fork.

## What Changed

- Rebranded the public fork from the upstream project identity to `VoiceSlate`
- Added Volcengine STT providers for fast and higher-accuracy transcription
- Added local correction history for transcript cleanup
- Added frontend usage stats and monthly API cost estimates
- Improved Windows capsule behavior, focus restoration, and output targeting
- Added a stable fallback hotkey path with `F8`
- Switched the public-safe default cloud base URL to `https://example.invalid`

## Recommended Setup

- STT: `volcengine-flash`
- LLM: `deepseek`
- Output mode: `clipboard`
- Primary hotkey: `Right Alt`
- Fallback hotkey: `F8`

## Known Notes

- `Right Alt` can still vary across some Windows input method and keyboard setups
- API cost numbers shown in the UI are local estimates, not provider billing records
- This release keeps attribution to the upstream OpenTypeless project in `NOTICE` and `LICENSE`
